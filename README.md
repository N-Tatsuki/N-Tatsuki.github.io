# 個人サイト

東京科学大学 博士後期課程 中谷 樹 の個人サイト。GitHub Pages で公開しています。

## ファイル構成

すべての内容が `index.html` 1ファイルにまとまっています。
（過去バージョンでは `data.js` / `main.js` に分かれていましたが、
アップロード時の食い違いを避けるため統合しました。）

| ファイル | 役割 | 編集頻度 |
|---|---|---|
| `index.html` | ページの構造・掲載内容・表示処理をすべて含む | よく編集する |
| `images/` | プロジェクトの写真を置くフォルダ | 写真追加時 |
| `style.css` | 配色とレイアウト | 見た目を変えるとき |

## 内容を更新する

`index.html` を開き、`<script>` タグの中にある `const SITE_DATA = {` から
始まるブロックを編集します。ここにプロフィール・研究テーマ・業績・
プロジェクト・学歴・職歴・リンクがすべて入っています。編集後、GitHub に
アップロードして `index.html` を上書きすれば、1〜2分ほどでサイトに反映されます。

### 業績を追加する

`publications` の配列に、次の形で追加します。

```js
{
  year: 2026,
  title: "論文タイトル",
  authors: "中谷 樹, 共著者",
  venue: "掲載誌名, 巻(号), ページ",
  type: "journal",
  themes: ["materials"],
  url: "https://doi.org/..."
}
```

- `type` … `journal`（論文）/ `international`（国際会議）/ `domestic`（国内会議・研究会）/ `award`（受賞）/ `grant`（競争的資金等の研究課題）/ `misc`（その他）
- `themes` … `themes` セクションの `id` を指定。複数テーマにまたがる業績は `["materials", "space-policy"]` のように並べると両方に表示される
- `url` … 空文字 `""` にするとリンクが表示されない

同じテーマ内では発表年の新しい順に自動で並びます。

### 競争的資金等の研究課題を追加する

`type: "grant"` を指定すると、そのテーマの下に「競争的資金等の研究課題」として
表示されます。専用の項目が使えます。

```js
{
  period: "2025 — 2026",
  title: "研究課題名",
  program: "日本学術振興会 科学研究費助成事業 特別研究員奨励費",
  role: "研究代表者",
  number: "課題番号 00A00000",
  type: "grant",
  themes: ["materials"],
  url: ""
}
```

`period` を指定すると、年号の欄に期間が表示されます。

### プロジェクトの写真を追加する

1. 画像を `images/` に置く（例 `images/space-award.jpg`）
2. `index.html` 内の該当プロジェクトの `image` に `"images/space-award.jpg"` と書く

横長（16:9 前後）の画像が最もきれいに収まります。表示は自動でトリミングされます。

### ナビゲーションを変更する

`index.html` の `<script>` 内、`var SECTIONS = [` から始まる配列を編集します。
左サイドバー（スマホでは上部の帯）の項目はここから生成されます。

## 動作確認

`index.html` をブラウザにドラッグ&ドロップすれば、そのまま表示を確認できます。
サーバーを立てる必要はありません。

## 配色を変える

`style.css` 冒頭の `:root` にある色をまとめて定義しています。ここを書き換えると
全体に反映されます。

| 変数 | 用途 |
|---|---|
| `--navy-900` | サイドバーの背景 |
| `--navy-700` | 見出し・リンクの紺 |
| `--brass` | 差し色（年号・罫線） |
| `--paper` | ページ全体の背景 |
